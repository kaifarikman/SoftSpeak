# 🗣️ SoftSpeak

SoftSpeak — это платформа анонимного общения с ML-профилированием, мгновенным подбором собеседников и возможностью «раскрытия» диалога в публичный чат по обоюдному согласию. Проект состоит из трех сервисов (backend, frontend и ML) и полностью разворачивается через Docker.

## 💡 Основные возможности

### 🔐 Аутентификация и регистрация
- Регистрация с подтверждением email через MailHog (dev) или SMTP (prod)
- JWT-авторизация с безопасным хранением токенов
- Валидация формата email при регистрации
- Мгновенное приветственное сообщение от бота после регистрации (без обновления страницы)
- Очистка локального состояния при смене аккаунта

### 🧠 Психологическое профилирование
- Интерактивный опрос через WebSocket в реальном времени
- Формирование векторного профиля пользователя на основе ответов
- ML-матчинг на основе `intfloat/multilingual-e5-base` и косинусной близости
- Админ-панель для управления вопросами опроса (категории, вопросы, активация/деактивация)

### 🎭 Анонимные чаты
- Мгновенный matchmaking с WebSocket-уведомлениями
- Случайные алиасы для участников (например, "Смелый Сокол") из базы данных
- Двухсторонняя логика «Раскрыться»: запрос → подтверждение → перенос чата в публичный раздел
- Загрузка и отправка фото/видео в чатах (настраивается в профиле)
- WebSocket-общение в реальном времени без задержек
- История сообщений с превью последнего сообщения

### 👥 Публичные чаты
- Автоматический перенос после обоюдного согласия на раскрытие
- Отображение аватаров и реальных имен пользователей
- Сохранение всей истории сообщений при переходе из анонимного режима
- WebSocket-общение без задержек

### 🤖 Чат с ботом
- Персональный диалог с AI-ботом
- История всех сообщений с ботом
- Интеграция с психологическим опросом

### ⚙️ Настройки пользователя
- Загрузка и изменение аватара (отображается в навигации и публичных чатах)
- Изменение username и bio
- Настройки уведомлений (анонимные чаты, публичные чаты)
- Настройки медиа (автозагрузка фото/видео)
- Смена пароля с валидацией
- Черный список пользователей (блокировка/разблокировка)

### 👨‍💼 Админ-панель
- Управление психологическим опросом:
  - Создание и редактирование категорий вопросов
  - Добавление, редактирование, активация/деактивация вопросов
  - Удаление вопросов
- Управление случайными именами для анонимных чатов:
  - CRUD операции для прилагательных (например, "Смелый", "Тихий")
  - CRUD операции для существительных (например, "Сокол", "Волк")
  - Активация/деактивация слов
- Статистика (количество категорий, вопросов, активных вопросов)

### 📱 Адаптивный интерфейс
- Полностью адаптивный дизайн для мобильных устройств
- Горизонтальная навигация на десктопе
- Гамбургер-меню на мобильных устройствах
- Оптимизированные размеры элементов для разных экранов

## 🧱 Архитектура и стек

| Сервис | Технологии | Роль |
|--------|-----------|------|
| Backend | FastAPI, SQLAlchemy, Alembic, PostgreSQL, WebSockets | REST API, matchmaking, хранение данных, файловый сервер, загрузка медиа |
| Frontend | React 18 + Vite, Context API, WebSocket-клиенты, Nginx | SPA-интерфейс, управление состоянием чатов, загрузка файлов |
| ML Service | FastAPI, PyTorch, sentence-transformers | Построение эмбеддингов и оценка совместимости |
| Инфраструктура | Docker Compose, MailHog, volumes, healthchecks | Отдельные контейнеры, проксирование `/api`, `/ws`, `/static` |

```
Browser → (Nginx фронтенда) → /api → FastAPI → PostgreSQL / ML
                               \→ /ws  → WebSocket эндпоинты
                               \→ /static → медиа-файлы (аватары, фото/видео из чатов)
```

## 🚀 Быстрый старт

1. **Клонируем репозиторий**:
   ```bash
   git clone <repo-url>
   cd SoftSpeak
   ```

2. **Создаем `.env`** (см. `.env.example`). Минимум:
   ```env
   POSTGRES_USER=softspeak_user
   POSTGRES_PASSWORD=softspeak_pass
   POSTGRES_DB=softspeak_db
   JWT_SECRET=измените-ключ-минимум-32-символа
   ML_MODEL_NAME=intfloat/multilingual-e5-base
   ```

3. **Запускаем сервисы**:
   ```bash
   docker-compose up -d --build
   ```
   > ML-сервису нужно скачать ~500 МБ модели; первый старт занимает 5–10 минут.

4. **Открываем**:
   - http://localhost:3000 — интерфейс
   - http://localhost:3000/admin — админ-панель (логин: `admin`, пароль: `admin`)
   - http://localhost:8000/docs — Swagger API
   - http://localhost:8025 — MailHog (просмотр отправленных email)

## ⚙️ Ежедневные команды

| Действие | Команда |
|----------|---------|
| Остановить все | `docker-compose down` |
| Остановить c очисткой volume | `docker-compose down -v` |
| Перезапустить сервис | `docker-compose restart frontend` |
| Пересобрать сервис | `docker-compose up -d --build backend` |
| Смотреть логи | `docker-compose logs -f backend` |
| Сбросить БД до нуля | `docker-compose down -v && docker volume rm softspeak_postgres_data || true && docker-compose up -d` |
| Очистить таблицы без удаления volume | `docker-compose exec db psql -U softspeak_user -d softspeak_db -c "TRUNCATE TABLE <tables> RESTART IDENTITY CASCADE;"` |
| Применить миграции | `docker-compose exec backend alembic upgrade head` |

## 🔐 Переменные окружения

## 🔄 Основные потоки работы

### Регистрация и первый вход
1. Пользователь регистрируется с email
2. Получает код подтверждения (MailHog в dev)
3. Вводит код → автоматический вход
4. Бот отправляет приветственное сообщение
5. Пользователь проходит психологический опрос
6. Профиль сохраняется в векторном виде

### Поиск собеседника (Matchmaking)
1. Пользователь нажимает "Смэтчиться"
2. Добавляется в очередь матчинга
3. ML-сервис вычисляет совместимость с другими пользователями
4. При нахождении совпадения создается анонимный чат
5. Оба пользователя получают уведомление через WebSocket
6. Чат открывается автоматически

### Раскрытие анонимного чата
1. Один пользователь нажимает "Раскрыться"
2. Отправляется запрос (`reveal_request`) второму пользователю
3. Второй пользователь видит уведомление и может согласиться
4. После обоюдного согласия чат становится публичным
5. Отображаются реальные имена и аватары
6. История сообщений сохраняется


## 🌐 Видение проекта

SoftSpeak — это гибрид психологического ассистента и безопасного мессенджера. Пользователь приходит поговорить, сначала проходит короткий диалог с ботом, затем попадает в очередь и мгновенно получает собеседника, максимально близкого по эмоциональному портрету. Общение стартует анонимно, но люди сами решают, переводить ли его в открытый режим: сначала один предлагает раскрыться, второй подтверждает, и только после обоюдного согласия чат переезжает в «публичные» с отображением аватаров и никнеймов. ML-сервис, FastAPI и React связаны единым WebSocket-потоком, поэтому SoftSpeak воспринимается как живая комната поддержки, где технологии вторят человеческой эмпатии. Это не просто чат, а платформа доверенного диалога, где приватность и открытость контролируются самими участниками, а AI помогает находить тех, кто действительно услышит.
